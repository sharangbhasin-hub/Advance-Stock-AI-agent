📈 Elite AI Trading Agent
Welcome to the Elite AI Trading Agent, a sophisticated, self-intelligent trading analysis tool designed for modern intraday and swing traders. This agent replicates the complex decision-making process of a professional trader by leveraging multi-timeframe analysis, advanced chart patterns, a suite of technical indicators, and cutting-edge AI for strategy formulation.

This project is an evolution of the "Stock Market Analyzer," enhanced with the advanced strategies outlined in the "AI Intraday" and "Intraday Trading Notes" documents.

🚀 Core Features
🧠 AI-Powered Strategy Engine
Google Gemini Integration: Utilizes a powerful LLM to analyze technical data, chart patterns, and news sentiment to generate concise, actionable trading plans.

Human-like Analysis: The AI follows a strict, rule-based logic derived from professional trading strategies, including trend analysis, breakout/retest confirmations, and risk management.

📊 Multi-Timeframe Analysis
Strategic View (15-Min Chart): Used to identify the dominant trend, key support and resistance levels, and overall market structure.

Tactical Execution (5-Min Chart): Used for precise trade entry and exit timing, candlestick pattern recognition, and real-time indicator monitoring.

🛠️ Advanced Technical Indicator Suite
Trend Following: 20, 50, and 200-period Exponential Moving Averages (EMAs).

Momentum: Relative Strength Index (RSI) and MACD.

Volume-Based: Volume-Weighted Average Price (VWAP) for intraday levels.

Volatility: Bollinger Bands to identify dynamic support and resistance.

⛓️ Integrated Options Chain Analysis
Real-time Data: Fetches the nearest-expiry options chain for any selected stock or index.

"Blue Zone" Strategy: Automatically highlights In-The-Money (ITM) options for calls and puts, as per the specified trading strategy.

Sentiment Indicator: Calculates and displays the Put-Call Ratio (PCR) based on Open Interest to gauge market sentiment.

✨ Modern & Stylish User Interface
Intuitive Layout: A tab-based design separates the AI Dashboard, Technical Charts, Options Chain, and News for a clean, organized workflow.

Interactive Charts: Powered by Plotly for a professional, dynamic charting experience.

Dark Theme: A sleek, modern interface designed for traders.

🔧 Installation & Setup
1. Clone the Repository
git clone [https://github.com/your-username/elite-ai-trading-agent.git](https://github.com/your-username/elite-ai-trading-agent.git)
cd elite-ai-trading-agent

2. Install Dependencies
Create a Python virtual environment and install the required packages.

python -m venv venv
source venv/bin/activate  # On Windows, use `venv\Scripts\activate`
pip install -r requirements.txt

3. Configure Environment Variables
Create a .env file in the root directory of the project. This file is used to securely store your API keys.

# Get your key from Google AI Studio: [https://makersuite.google.com/](https://makersuite.google.com/)
GOOGLE_API_KEY="your_google_api_key_here"

# Get your key from [https://newsapi.org/](https://newsapi.org/)
NEWSAPI_KEY="your_newsapi_key_here"

4. Run the Application
Launch the Streamlit application from your terminal:

streamlit run app.py

📋 How to Use the Agent
Select Market & Stock: Use the sidebar to choose a major index (like NIFTY 50) and then decide whether to analyze the index itself or an individual stock within it.

Run Analysis: Click the "Run Full Analysis" button to initiate the data fetching and analysis process.

Review AI Strategy: The main "AI Strategy & Dashboard" tab will display a complete trading plan generated by the AI, along with a live dashboard of key metrics.

Deep Dive into Charts: Switch to the "Technical Charts" tab to view the interactive 15-minute and 5-minute charts with all indicators plotted.

Check Options Data: If trading options, visit the "Options Chain" tab to see ITM contracts and the current Put-Call Ratio.

Stay Informed: Look at the "Latest News" tab for recent headlines that could impact the asset.
